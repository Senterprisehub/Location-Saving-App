2 Deploy & Get the Web App URL

Open Google Apps Script
Go to script.google.com in a new tab and sign in with the Google account you want your data stored in.
Create a new project
Click + New project on the top-left. Apps Script will open a blank Code.gs editor for you.
Paste the code
Select everything in the editor (Ctrl/⌘ + A), delete it, then paste the code you copied in Step 1 (Ctrl/⌘ + V).
Save the project
Press Ctrl + S (Windows) or ⌘ + S (Mac), or click the 💾 Save icon in the toolbar.
Start a new deployment
Click the blue Deploy button (top-right) → select New deployment.
Choose "Web app" as the type
Click the ⚙ gear icon next to "Select type" → choose Web app.
Set permissions
Fill in the fields exactly as shown:
• Execute as: Me (your@gmail.com)
• Who has access: Anyone
⚠️
Important "Who has access" must be Anyone — otherwise the browser cannot reach your Web App and sync will fail with a CORS error.
Authorize the script
Click Deploy. Google will ask for permission the first time:
1. Authorize access
2. Choose your Google account
3. Click Advanced → Go to [project] (unsafe)
4. Click Allow
ℹ️
Why "unsafe"? That warning appears for any personal Apps Script. Since you wrote this script yourself, it is safe to proceed.
Copy the Web App URL
After deployment, a dialog shows the Web app URL. It looks like:
https://script.google.com/macros/s/AKfy…/exec
Click the Copy button next to it.
You can also find this URL later at Deploy → Manage deployments.
✅
Almost done Paste the URL you copied into the Bridge URL field just below and click Save Script URL.
