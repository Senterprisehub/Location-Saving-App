2. Deployment Guide (10 Steps)
▼
Open Google Apps Script
Go to script.google.com and sign into your Google account.
Create a new project
Click + New project in the top left corner.
Paste the Code
In the editor, clear existing template code (Ctrl/Cmd + A, Backspace) and paste the code from Step 1 above.
Save Project
Click the 💾 Save disk icon or press Ctrl + S / Cmd + S.
Start Deployment
Click the blue Deploy button at the top right, then select New deployment.
Select Web App Type
Click the gear icon ⚙️ next to "Select type" and choose Web app.
Configure Permissions (CRITICAL)
• Execute as: Me (your@gmail.com)
• Who has access: Anyone
⚠️
Mandatory Setting"Who has access" MUST be set to Anyone so the tracker can sync without OAuth redirects.
Authorize Access
Click Deploy → Click Authorize access → Select your Google account → Click Advanced → Click Go to Untitled project (unsafe) → Click Allow.
Copy Web App URL
Copy the generated URL under "Web app". It MUST end with /exec.
ℹ️
Use /execNever use the /dev test URL.
Updating Code in the Future
If you ever edit Code.gs, you must click Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy.
