2 Deploy & Get the Web App URL
▼
Open Google Apps Script
Go to script.google.com and sign in.
Create a new project
Click + New project on the top-left.
Paste the code
Select everything (Ctrl/⌘ + A), delete, then paste the code from Step 1.
Save the project
Press Ctrl + S / ⌘ + S.
Start a new deployment
Click the blue Deploy button → New deployment.
Choose "Web app" as the type
Click the ⚙ gear icon next to "Select type" → Web app.
Set permissions

• Execute as: Me
• Who has access: Anyone
⚠️
Critical "Who has access" must be Anyone. Otherwise the browser receives an HTML login page.
Authorize the script
Click Deploy → Authorize access → choose account → Advanced → Go to [project] (unsafe) → Allow.
Copy the Web App URL
Copy the URL — it ends in /exec.
ℹ️
Use the /exec URL Never use /dev.
⚠ Re-deploy after code changes
After editing Code.gs, go to Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy.
